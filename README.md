# Kilocode DVD Screensaver - CHRISTMAS CHAOS EDITION 🎄🚀

A wild, chaotic take on the classic DVD screensaver, featuring the Kilocode logo with unpredictable transformations and effects! Now with festive Christmas flair!

**[🎅 View Live Demo](https://markijbema.github.io/dvd-demo/)**

## Features

### Classic DVD Behavior
- Bounces around the screen like the nostalgic DVD logo
- Changes colors when hitting edges
- Special effects when hitting corners

### Christmas Features 🎄

**Festive Decorations:**
- ❄️ Continuous snowfall with various snowflake styles
- 🎅 Santa hat on the bouncing logo
- 🔴🟢🔵 Twinkling Christmas lights at the top
- 🍬 Candy cane border at the bottom
- 🎁 Random bouncing presents

**Holiday Messages:**
- "HO HO HO! 🎅"
- "MERRY CHAOS-MAS!"
- "SANTA SAW THAT CORNER HIT"
- "DECK THE HALLS WITH BOUNCING LOGOS"
- "🎄 TREE-MENDOUS! 🎄"
- And more festive madness!

### Chaos Features 🎉

**Random Transformations:**
- Logo randomly transforms into emojis (🚀 rocket, 🍕 pizza, 🦄 unicorn, 👾 alien, 🤖 robot, 🎄 tree, 🎁 present, 🎅 santa, ⛄ snowman, 🦌 reindeer)
- Returns to original Kilocode logo after 2 seconds

**Visual Effects:**
- 💥 Emoji explosions on corner hits (now with Christmas emojis!)
- 🌈 Matrix rain effect with falling green characters
- ✨ Magical portals that teleport the logo (Christmas-colored portals!)
- 🎮 Glitch effects
- 🎨 Disco mode with flashing rainbow OR Christmas red/green backgrounds
- 💫 Glowing particle trails
- 🔔 Jingle bells cascade effect
- 🌨️ Snow blizzard mode

**Physics-Breaking Madness:**
- Speed boosts (3x velocity)
- Spinning mode
- Reverse gravity
- Random size changes
- Portal teleportation

**Secret Messages:**
- Random messages appear and spin around:
  - "KILO RULES!"
  - "404: GRAVITY NOT FOUND"
  - "DVD WHO?"
  - "EDGE LORD"
  - "MAXIMUM VELOCITY"
  - And more!

### Trigger System

- **Every 5 bounces:** Random crazy event
- **Every 10 bounces:** Multiple effects at once
- **Corner hits:** Maximum chaos activated
- **Random events:** Every 15 seconds

## Usage

Simply open `index.html` in your browser and watch the chaos unfold!

```bash
# Clone the repository
git clone https://github.com/markijbema/dvd-demo.git

# Open in browser
open index.html
```

Or visit the live demo: **[https://markijbema.github.io/dvd-demo/](https://markijbema.github.io/dvd-demo/)**
